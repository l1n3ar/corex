# agentx

Planned. An agent framework to be built natively on [attnx](../attnx) and [basisx](../basisx) primitives: tool calling, RAG, deep research, human-in-the-loop, memory, context management, and a virtual filesystem.

## Related

- **[agentz](../agentz)**: the same agent, built on LangChain, LangGraph, and LangSmith instead, for benchmarking against agentx once both exist.
